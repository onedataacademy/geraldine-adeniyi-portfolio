# Geraldine Adeniyi — Portfolio Website

I prepared this revised version to position Geraldine around business analytics, business analysis, process improvement and decision support. It is a static website that can be hosted on Cloudflare Pages from a GitHub repository.

## Files

- `index.html`: all page content, sections, contact links and proposed project briefs.
- `styles.css`: colours, typography, layout, mobile styles and accessibility settings.
- `script.js`: mobile navigation and project filters.
- `assets/geraldine-adeniyi.jpg`: selected professional portrait.
- `assets/favicon.svg`: browser icon.

All local visual assets are included. The project cards and hero use bundled stock photographs. Typography uses system fonts and does not require a remote font service. There are no build dependencies, API keys or paid services.

## Open locally

Unzip the folder, then open `index.html` in a browser. For a local server, run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## GitHub and Cloudflare Pages

1. Create a GitHub repository, then upload the contents of this folder. `index.html` must be at the repository root.
2. In Cloudflare, open Workers & Pages, create a Pages project and connect the repository.
3. Select **None** as the framework preset. Leave the build command empty. Use `/` as the output directory and leave the root directory blank.
4. Deploy. Subsequent commits to the selected production branch update the website.
5. Once the final domain is chosen, add a canonical URL and sitemap before search-engine submission.
